# B-{{EPIC}}-X：<标题>

> **使用方式**：每次开 B-{{EPIC}}-* 批次前 30 分钟内复制本模板填好；工程师 + Claude Code 把这份 brief 当会话起点。完成后保留在 `temp/batch-briefs/B-{{EPIC}}-X.md`，作为后续同类 batch 的参照样本。

## Goal

1-2 句话描述"done 的样子"。够具体，让别人不看 brief 也能反推这个 batch 是否成功。

例：实现 X 抽象基类与脚手架，使后续 Y 可以通过继承一个 ABC 完成所有协议层工作。

## Scope

- **in**:
  - 列具体可观测的产出物（新增文件 / 改动模块 / 新加端点 / 新加测试）
- **out**（明确不做，防 scope creep）:
  - 列出"看起来相关但本批不做"的事项

## Constraining ADRs / 设计章节

- **ADR-X**：一句话约束 + [设计文档锚点](../../docs/<请替换为设计文档路径>)
- **设计文档 §X.Y**：本批主要参照章节
- **跑偏自检 6 条**：每次完成必跑
